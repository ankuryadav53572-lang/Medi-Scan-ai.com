# 🚀 MediScan AI – Your Smart, Secure Health Companion

**MediScan AI** is a privacy-focused AI web application that helps users understand potential health conditions through symptom input and medical image analysis.  
This project was built as **Project 1** during my **Remote Internship at Vytoflow Tech** (Hard Level Domain).

---

## 🧠 Features

- **Medical Image & Symptom Analysis:** Upload a medical image and describe your symptoms to receive an AI-generated diagnosis and treatment suggestions.
- **Privacy First:** Uploaded images are processed securely and deleted immediately to ensure user privacy.
- **Save & Download Reports:** Diagnosis reports are saved for future reference and can be easily downloaded.
- **Secure Authentication:** User authentication and personalized access with **Clerk**.
- **Modern UI/UX:** A clean, responsive, and accessible frontend designed with **Tailwind CSS**.

## 🛡️ Privacy Focus

At MediScan AI, user trust is a top priority:

- Medical images are **not stored** — they're processed and immediately deleted.
- Only **diagnosis reports** (text) are saved securely for user reference.
